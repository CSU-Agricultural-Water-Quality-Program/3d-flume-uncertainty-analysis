# Unused old R scripts

`base_flume.R` is the previous main script, archived unchanged. It retains the
fitting switch and commented models 1, 2, and 4 for historical reference. Its
original path setup refers to its former location; do not run it as the final
analysis. The current main script is `../bayes_flume.R`.

`preview-flume-uncertainty-components.R` is a retired alias that forwards to
`../tools/regenerate-flume-figures.R`. It is retained for provenance. Use the
named tool directly when regenerating figures from a saved fit.
